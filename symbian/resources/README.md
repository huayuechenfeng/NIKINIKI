# NIKINIKI resources

- `font/switch_font.ttf` is the complete Source Han Sans-derived font formerly
  obtained through the wiliwili resource tree.
- `font/nikiniki_cjk_subset.ttf` is a size-reduced derivative generated by
  `tools/build_symbian_font_subset.py`. Its internal family name is
  `NIKINIKI CJK`, so it does not retain Adobe's reserved `Source` name.
- Both fonts remain under SIL Open Font License 1.1; see `font/LICENSE.txt`.
- `pictures/video-card-bg.png` is retained from wiliwili commit `88e5876` and
  is distributed under GPL-3.0 with the rest of the project.

The app icon and its separate provenance are documented in
`symbian/app/icons/README.md`.
