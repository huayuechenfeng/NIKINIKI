# wiliwili for Symbian³ 阶段归档

本目录保留 NIKINIKI 定名前后形成的追加式阶段报告、早期总体设计和旧版代理指南。
它们包含大量有价值的开发历程，但同时混合了当前状态、旧计划、失败方案和已经被替代的
产品决定，因此不再作为接手入口。

- 当前状态：`docs/STATUS_ZH.md`；
- 当前路线图：`docs/ROADMAP_ZH.md`；
- 当前架构：`docs/developer/`；
- 可复用实验结论：`docs/research/`。

历史名称、版本号和当时的叙述按原样保留。若旧正文称自己为“单一事实来源”，以目录顶部
新增的 Historical 标记和上述活文档为准。
